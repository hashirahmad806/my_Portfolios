# Agent Terminal & System Telemetry HUD

## Context & Decision
To demonstrate Hashir's technical expertise as an AI Agent & Full-Stack Systems Engineer interactively rather than statically, we decided to build an **Agent Terminal** (in-browser interactive agent execution simulator) coupled with a persistent **System Telemetry HUD** (real-time telemetry and CAD control dock).

## Considered Options
- Static text descriptions: Fails to tangibly demonstrate agentic workflow logic and RAG retrieval mechanisms.
- External demo links only: Requires visitors to navigate away and authenticate.
- Embedded Agent Terminal & Telemetry HUD (Chosen): Gives immediate tactile proof of cognitive architecture (LangChain, LangGraph, Vector Search) directly in the browser with keyboard accessibility (`~` / `Ctrl+K`) and live system feedback.
