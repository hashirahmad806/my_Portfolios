# Architectural Blueprint Grid System

## Context & Decision
The user requested a high-engineering aesthetic that preserves structural "blocks" across the portfolio rather than a generic flat background. We decided to implement a full-page **Architectural Blueprint Grid System**: a precision drafting grid with subtle crosshair coordinate points (`+`), smooth radial masking, and dynamic theme tokens. This replaces arbitrary wireframe boxes with a unified, high-performance background architecture across Hero and downstream sections.

## Considered Options
- Flat Studio Spotlight: Lacks technical depth and structural engineering personality.
- Static 80px Linear Grids: Felt like blocky, unmasked container wireframes.
- Architectural Blueprint Grid (Chosen): Provides precision technical framing, cohesive whole-page continuity, and pristine contrast in both Dark and Light modes.
