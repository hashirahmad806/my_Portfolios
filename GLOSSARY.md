# Portfolio Design System

The visual language, spatial grid architecture, and thematic styling for Hashir's engineering portfolio.

## Language

**Agent Terminal**:
An interactive in-browser CLI simulator that executes agentic workflows (RAG, state graph traversal, architecture diagnostics).
_Avoid_: Modal popup, chatbot window

**Architectural Blueprint Grid**:
A high-precision background drafting grid with intersection crosshairs (`+`) and radial masking that anchors the entire page hierarchy.
_Avoid_: Wireframe box, container lines, background blocks

**Atmospheric Studio Canvas**:
The ambient lighting layer that illuminates the viewport and guides visual hierarchy toward primary interaction points.
_Avoid_: Blank background, plain background

**Capability Telemetry Workbench**:
An interactive technical competency audit interface coupling live telemetry metrics, production code nodes, and real-time benchmark simulation.
_Avoid_: Skills progress bar, percentage chart

**Dynamic Theme Elevation**:
The dual-state color and contrast architecture ensuring WCAG AAA compliance and high optical fidelity across both Dark and Light modes.
_Avoid_: Inverted colors, washed-out theme

**Environmental Pointer Lighting**:
The interaction paradigm where the native hardware OS cursor is preserved, and user spatial presence is communicated through interactive canvas lighting and magnetic element feedback rather than simulated cursor elements.
_Avoid_: Custom dot cursor, lagging ring, fake pointer

**System Telemetry HUD**:
A persistent heads-up display anchored to the viewport presenting real-time system metrics, CAD coordinates, and console triggers.
_Avoid_: Status bar, footer banner
