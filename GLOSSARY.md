# Portfolio Design System

The visual language, spatial grid architecture, and thematic styling for Hashir's engineering portfolio.

## Language

**Architectural Blueprint Grid**:
A high-precision background drafting grid with intersection crosshairs (`+`) and radial masking that anchors the entire page hierarchy.
_Avoid_: Wireframe box, container lines, background blocks

**Atmospheric Studio Canvas**:
The ambient lighting layer that illuminates the viewport and guides visual hierarchy toward primary interaction points.
_Avoid_: Blank background, plain background

**Dynamic Theme Elevation**:
The dual-state color and contrast architecture ensuring WCAG AAA compliance and high optical fidelity across both Dark and Light modes.
_Avoid_: Inverted colors, washed-out theme
